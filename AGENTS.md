# Project

Smart Campus Room Availability Checker.

A read-only React/TypeScript application using fictional room-booking data.

# Constraints

- Preserve AC1–AC6 and the existing UI.
- No backend, login, database, new booking creation, new features, or new dependencies.

# Engineering Rules

- Prefer pure functions and minimal changes.
- Preserve the existing checkAvailability inputs and outputs.
- Do not mutate booking fixtures.
- Use at most two justified patterns; zero patterns is acceptable.
- Keep the existing responsive UI feedback.

# Verification

- Read package.json to identify the actual test and build commands.
- Run existing tests and add focused regression tests only when necessary.
- Report changed files, rationale, and real test evidence.
